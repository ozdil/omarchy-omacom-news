# Omacom News (omarchy-omacom-news)

Official Omacom Foundation news dispatches, announcements, and desktop notifications for Omarchy Linux.

## Features
- 100% Native Rust engine (`omacomnews-engine`).
- Desktop notifications (`libnotify` / `notify-send`) for fresh Omacom announcements.
- Native Omarchy Quickshell UI (`Panel.qml`) matching OmaRank's design.
- Zero icons / emojis / Nerd Font glyphs ("simge kullanmayalım").
- Offline resilience with local and built-in dispatch caching.
- Native Arch Linux package build (`PKGBUILD`).
